# Lumière

イラストの光源、色温度、立体感をブラウザ上で調整するアプリです。画像処理は端末内で行われ、画像のアップロード先はありません。

## 起動

このフォルダでローカルサーバーを起動し、表示された URL をブラウザで開きます。

```sh
node server.cjs
```

その後、`http://127.0.0.1:8000` を開いてください。手動でのライブラリインストールは不要です。深度推定モデルとフォントの取得にはネット接続が必要です。接続できない場合も照明と色温度の調整は使えます。

## GitHub Pages

`index.html` などの静的ファイルはリポジトリのルートにあります。GitHub Pages の公開元を `main` ブランチの `/(root)` に設定すると公開できます。`server.cjs` はローカル確認用で、Pages では使いません。初回の深度推定にはモデルのダウンロードが必要です。

## 操作

- 「画像を開く」またはドラッグ＆ドロップで PNG、JPEG、WebP、SVG を読み込みます。
- イラスト上の光源マーカー、または左の位置マップをドラッグして光の位置を変えます。
- 光の強さ、広がり、高さ、色温度、凹凸の深さ、法線の強さ、影の濃さを調整します。
- 画像を開くと、Depth Anything V2 Small が画像の内容から深度マップを推定します。初回はモデルをダウンロードするため、ネット接続が必要です。画像はブラウザ内で処理され、外部に送信されません。
- 「深度」で手前と奥の明るさや陰影の差を調整します。「深度マップを描く」では白いブラシで手前、黒いブラシで奥を指定できます。「推定結果に戻す」で手動修正を消せます。
- 推定した深度から法線マップを生成し、光の当たる面の向きを反映します。深度を描き直すと法線も更新されます。「法線の強さ」で効きを調整し、キャンバス上の「法線」でマップを確認できます。
- 「落ち影」は推定した深度から光源に応じて影を作ります。「自然」は従来の仕上がり（落ち影0%）、「ソフト」「ドラマ」で段階的に強められます。演出の強さと影の柔らかさも個別に調整できます。
- キャンバス上の「深度」ボタンで推定マップを確認できます。
- 「比較」で境界線を動かし、調整前後を見比べます。「元画像」は押している間だけ原画を表示します。スペースキーでも原画を表示できます。
- 「PNGを書き出す」で調整後の画像を保存します。

立体感の調整は元画像の明暗から細かな凹凸を推定し、深度から生成した法線で大きな面の向きを補います。深度は単一画像から推定した相対的な奥行きです。実際の距離やレイヤーの奥行き情報ではないため、イラストの内容によっては手動修正が必要です。

深度推定には [Depth Anything V2 Small](https://huggingface.co/onnx-community/depth-anything-v2-small) を [Transformers.js](https://huggingface.co/docs/transformers.js/) でブラウザ内実行します。
