# Lumière

イラストの光源、色温度、立体感をブラウザ上で調整するアプリです。画像処理は端末内で行われ、画像のアップロード先はありません。

## 起動

このフォルダでローカルサーバーを起動し、表示された URL をブラウザで開きます。

```sh
node server.cjs
```

その後、`http://127.0.0.1:8000` を開いてください。手動でのライブラリインストールは不要です。深度推定モデルとフォントの取得にはネット接続が必要です。接続できない場合も照明と色温度の調整は使えます。

## GitHub Pages

公開先は https://penguin045.github.io/lumiere/ です。`index.html` などの静的ファイルはリポジトリのルートにあり、`main` ブランチの `/(root)` から公開します。`server.cjs` はローカル確認用で、Pages では使いません。初回の深度推定にはモデルのダウンロードが必要です。

## 操作

- 「画像を開く」またはドラッグ＆ドロップで PNG、JPEG、WebP、SVG を読み込みます。
- 光源を最大4個まで追加できます。光源一覧やイラスト上のマーカーで選択し、それぞれの位置・強さ・広がり・奥行き・色温度・照射方向を調整します。
- 「前から」は面の明暗と落ち影を作ります。「逆光」は推定深度と画像の透明度から輪郭を見つけ、光源側の縁を照らします。光の通り道に光源より手前の層があると輪郭光が遮られます。各光源で個別に切り替えられます。
- 「光源の奥行き」は画像面からの距離です。前から照らす場合、画像面に近いほど落ち影が長くなり、面に当たる光の角度も変わります。逆光では背後に離すほど輪郭の光が広がり、手前の層に遮られやすくなります。
- 凹凸の深さ、法線の強さ、影の濃さは画像全体に適用します。「接地影」は深度の近い面の重なりに短い影を加え、0%から強さを調整できます。
- 画像を開くと、Depth Anything V2 Small が画像の内容から深度マップを推定します。初回はモデルをダウンロードするため、ネット接続が必要です。画像はブラウザ内で処理され、外部に送信されません。
- 「深度」で手前と奥の明るさや陰影の差を調整します。「深度マップを描く」では白いブラシで手前、黒いブラシで奥を指定できます。「推定結果に戻す」で手動修正を消せます。
- 推定した深度から法線マップを生成し、光の当たる面の向きを反映します。細かな傾きに加えて広い範囲の傾きも読み取るため、球体のような丸い面にも陰影が付きます。深度を描き直すと法線も更新されます。「法線の強さ」で効きを調整し、キャンバス上の「法線」でマップを確認できます。法線の計算には WASM を使い、利用できない環境では JavaScript に切り替わります。
- 「落ち影」は推定した深度から光源に応じて影を作ります。「自然」は落ち影0%、「ソフト」「ドラマ」で段階的に強められます。影の柔らかさは遮る面との深度差にも応じて変わり、演出の強さと柔らかさを個別に調整できます。
- キャンバス上の「深度」ボタンで推定マップを確認できます。
- 「比較」で境界線を動かし、調整前後を見比べます。「元画像」は押している間だけ原画を表示します。スペースキーでも原画を表示できます。
- 「PNGを書き出す」で調整後の画像を保存します。

立体感の調整は元画像の明暗から細かな凹凸を推定し、深度から生成した法線で大きな面の向きを補います。深度は単一画像から推定した相対的な奥行きです。実際の距離やレイヤーの奥行き情報ではないため、イラストの内容によっては手動修正が必要です。

深度推定には [Depth Anything V2 Small](https://huggingface.co/onnx-community/depth-anything-v2-small) を [Transformers.js](https://huggingface.co/docs/transformers.js/) でブラウザ内実行します。

## WASM の再ビルド

`normal-map.wasm` はビルド済みで、アプリを使うだけなら Rust のインストールは不要です。法線計算を変更した場合は、Rust の `wasm32-unknown-unknown` ターゲットを用意して次を実行します。

```sh
./scripts/build-wasm.sh
```
